HVAC Pro PWA

1. Sube todos los archivos de esta carpeta a un alojamiento HTTPS estático.
2. Abre la URL en Safari desde el iPhone.
3. Pulsa Compartir > Añadir a pantalla de inicio.
4. Tras la primera apertura, la aplicación queda disponible sin conexión.

Opciones sencillas de alojamiento:
- GitHub Pages
- Netlify
- Cloudflare Pages

Nota: un service worker no funciona abriendo index.html directamente como archivo local; necesita HTTPS o localhost.
